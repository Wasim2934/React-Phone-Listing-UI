# React Phone Listing UI

A responsive **Phone Listing UI** built with **React.js** and **Tailwind CSS**.  
This project dynamically renders multiple phone cards using reusable components and displays product details like image, title, rating, reviews, features, offers, and pricing.
---

## Live Demo - https://wasim2934.github.io/React-Phone-Listing-UI/

## 🚀 Features

- Dynamic rendering using reusable React components
- Clean product card layout
- Responsive design for mobile, tablet, and desktop
- Product image, rating, reviews, specs, offers, and price section
- Styled using Tailwind CSS
- Beginner-friendly React project for practicing props and component structure

---

## 🛠️ Tech Stack

- **React.js**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **Vite**
